# 🍽️ Smart Restaurant Menu Management App (Powered by Gemini 1.5 Pro)

## 🧾 Overview

This interactive **Smart Restaurant Menu Management App** is built with **Streamlit** and powered by **Google Gemini 1.5 Pro**. It assists restaurant owners and event planners in:

- 🎉 Planning themed events
- 🍴 Generating personalized food menus
- ♻️ Managing leftovers sustainably

Harness the power of **GenAI** to streamline hospitality operations with smart automation and creative suggestions.

---

## ✨ Features

- 🎊 **Event Manager** – Get AI-curated plans with menu ideas, decoration tips, slogans, and hashtags.
- 🍔 **Food Menu Recommender** – Generate complete menus based on meal type, dietary needs, and spice preference.
- 🥡 **Leftover Optimizer** – Create preservation strategies, recipes, and donation ideas from surplus food.
- 🔐 **Secure API Integration** – Uses Streamlit Secrets to manage Google Gemini API keys safely.
- 📋 **AI Text Area Output** – Automatically populates rich, scrollable responses with Gemini 1.5 Pro.
