# 👨‍🍳 AI Chef Recipe Generator

## 🧾 Overview

The **AI Chef Recipe Generator** is a powerful and intuitive Streamlit-based web application that allows users to create customized recipes based on their preferences, uploaded images, or PDF documents. The app leverages **Google’s Gemini API** to generate rich, detailed recipes that include:

- Ingredients  
- Step-by-step instructions  
- Cooking time  
- Serving size  
- Dietary considerations  

---

## ✨ Features

- 📝 **User Input:** Enter dietary preferences, cuisine type, or available ingredients.
- 🖼️ **Image Upload:** Upload images of ingredients or dishes to generate recipe suggestions.
- 📄 **PDF Upload:** Add recipe requirements or custom preferences via PDF.
- 🌍 **Cuisines/Seasons-Based Recipes:** Get recipes tailored to different cuisines or seasonal ingredients.
- 🍱 **Leftover Ingredients Recipes:** Use up your leftover ingredients efficiently.
- 🤖 **AI-Generated Recipes:** Powered by Google's Gemini for smart and creative culinary ideas.
- 🧑‍💻 **Interactive UI:** Built with Streamlit for a smooth user experience.
