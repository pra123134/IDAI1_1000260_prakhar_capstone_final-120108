AI Chef Recipe Generator
Overview
The AI Chef Recipe Generator is a Streamlit-based web application that allows users to create recipes based on their preferences, uploaded images, or PDFs. The application integrates Google’s Gemini API for generative AI capabilities to provide detailed recipes, including ingredients, step-by-step instructions, cooking time, serving size, and dietary considerations.

Features
* User Input: Enter dietary preferences, cuisine type, or available ingredients.
* Image Upload: Upload images of ingredients or dishes for AI-based recipe generation.
* PDF Upload: Provide additional recipe details or requirements via PDF.
* AI-Generated Recipes for different cuisines or seasonal ingredients based on season- Receive detailed recipes generated by the Gemini AI model.
* AI-Generated Recipes for the leftover ingradients 
* AI-Generated Recipes: Receive detailed recipes generated by the Gemini AI model.
* Interactive UI: A user-friendly interface built using Streamlit.

Installation
Prerequisites
* Python 3.8 or higher
* pip (Python package manager)
Required Python Libraries
Install the required Python libraries by running:
pip install streamlit google-generativeai PyPDF2 Pillow

Usage
Step 1: Clone the Repository
Clone this repository to your local machine:
git clone <repository_url>
cd <repository_directory>
Step 2: Set Up the API Key
Replace the GEMINI_API_KEY placeholder in the script with your actual Google Gemini API key.
Alternatively, you can set the API key as an environment variable:
export GEMINI_API_KEY="your_api_key_here"
Step 3: Run the Application
Run the Streamlit app using the following command:
streamlit run app.py
Step 4: Access the Application
Open your web browser and navigate to:
http://localhost:8501

How It Works
1. Enter Preferences: 
o Provide dietary preferences, cuisine type, or ingredients in the text area.
2. Upload an Image: 
o Upload an image of ingredients or a dish (optional).
3. Upload a PDF: 
o Upload a PDF containing additional recipe details or requirements (optional).
4. Generate Recipe: 
o Click the "Generate Recipe" button to receive your custom AI-generated recipe.
