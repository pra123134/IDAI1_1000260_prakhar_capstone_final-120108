# 👨‍🍳 AI-Powered Restaurant Manager Master Course

## 🧾 Overview

The **AI-Powered Restaurant Manager Master Course** is an interactive Streamlit application designed to help aspiring and current restaurant managers learn, reflect, and apply strategic decision-making with the support of Google’s Gemini AI. Each course module generates dynamic case studies, expert insights, summaries, and interactive journaling prompts to simulate real-world restaurant challenges.

---

## ✨ Features

- 📚 **Course Modules:** Learn key restaurant management topics such as staffing, inventory, AI integration, customer experience, and more.
- 🔄 **Dynamic Case Studies:** Generate realistic case studies using Gemini AI.
- 💡 **AI Hints:** Get quick strategic hints to approach each scenario.
- 🧠 **Expert Guidance:** Receive structured best practices, decision advice, and pitfalls to avoid.
- 📝 **Reflection Journal:** Write and save your reflections on each case.
- 📒 **Summary Notes:** Review key takeaways for each module.
- 🗂️ **Sidebar Navigation:** Easily select different learning modules.
